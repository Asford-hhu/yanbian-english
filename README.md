# 砚边 · 一个人的英语备考手记

一个纯静态、可直接部署的英语备考站：面向四六级 + 大英赛，覆盖阅读 / 写作表达库 / 语境词汇 / 听说训练 / 错题本 / 模考计时 / 进度统计。全部学习数据保存在浏览器本地（localStorage），可导入导出。零后端、零密钥、零依赖。

---

## 一、文件结构

```
marginalia/
├── index.html    页面结构（直接打开即可用）
├── styles.css    设计系统（学术编辑风 × 手账温度，浅/深双主题）
├── data.js       内置精选学习内容（阅读/表达/词汇/听说/模考/资源）
├── app.js        核心逻辑（状态/路由/概览/研习/阅读/写作）
├── app2.js       其余模块（词汇/听说/错题/模考/进度/资源）
└── README.md     本说明
```

> 没有 package.json、没有构建步骤、没有 npm 依赖 —— 就是最朴素的静态网页。

## 二、本地预览（任选其一）

**方式 A：直接打开**
双击 `index.html` 即可。个别浏览器对 `file://` 下的字体/发音有安全限制，若朗读无效，用方式 B。

**方式 B：起一个本地服务器（推荐）**
在本目录打开终端，任选一条：

```bash
# Python 3
python -m http.server 8000

# 或 Node（需 npx）
npx serve -l 8000
```

然后浏览器访问 `http://localhost:8000`。

## 三、部署到 Cloud Studio（腾讯云）

Cloud Studio 是云端 IDE，可直接运行并「部署」静态站点为可访问链接。步骤如下：

1. **上传代码**：进入 [Cloud Studio](https://cloudstudio.net/)，新建一个工作空间（Blank / Node.js 模板均可），把本目录的 6 个文件全部上传/拖入到工作空间根目录。

2. **启动静态服务**：在 Cloud Studio 的终端里执行：

   ```bash
   python3 -m http.server 8080
   ```

   （若镜像无 python3，用 `npx serve -l 8080`，首次会提示安装依赖，回车确认即可。）

3. **打开预览**：服务启动后，终端会输出一个访问地址（形如 `https://xxxx.cloudstudio.work` 或带端口的预览链接），点击即可在浏览器打开你的网站。Cloud Studio 通常会自动识别端口并给出「预览 / 访问」按钮。

4. **固定为分享链接（可选）**：在端口预览面板里，把该端口的「访问方式」从「仅自己」改为「公开」，即可得到一个可直接分享的网址。

> 提示：Cloud Studio 免费额度有使用时长限制，长期挂机请留意；本项目是纯静态文件，也可放到任意静态托管（如 GitHub Pages、腾讯云 COS、Vercel、Netlify）获得永久免费链接——把整个目录传上去、入口设为 `index.html` 即可。

## 四、功能与数据说明

| 模块 | 能做什么 |
|---|---|
| 概览 | 距大英赛倒计时、每日打卡、连续天数、学习统计、快速入口 |
| 研习 | 四步学习路径（打底→输入→输出→巩固） |
| 阅读 | 3 篇精选文章 + 理解题，答错自动进错题本，可朗读全文 |
| 写作 | 22 条分类高级表达，收藏成「我的表达夹」，可朗读 |
| 词汇 | 16 个语境化单词（整句记忆），可加入生词本、朗读例句 |
| 听说 | 3 段场景听力 + 变速朗读 + 听写填空 + 原文显隐 |
| 错题本 | 自动收集答错题目，附解析，可移除/清空 |
| 模考 | 分部分计时、答题、自动判分，成绩计入统计 |
| 进度 | 打卡热力图、近七日活跃、正确率、模考用时 |
| 资源 | 名师课程 / 官方考试网 / 词典工具等实时资源导航 |

**发音**：使用浏览器内置的 Web Speech API（Web 语音合成），无需联网或密钥。首次点击「朗读」时若无声，请检查系统音量或换 Chrome / Edge 浏览器。

**数据管理**：左侧栏底部（手机端在菜单内）的「数据」按钮 → 导出备份为 JSON / 导入 / 清空。数据只存在你的浏览器里，换设备需靠导入导出迁移。

**主题切换**：左侧栏底部（手机端顶栏）的 ◐ 按钮切换浅色 / 深色。

内置内容是精挑细选的**离线样例**（够跑通完整体验）。要跟进实时课程与真题，用「资源」页里的外部链接（B 站刘晓燕、四六级/大英赛官网、剑桥写作批改等）。如需扩充内置题库，直接编辑 `data.js` 中对应数组即可，格式照抄现有条目。
